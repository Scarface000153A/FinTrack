Core Features and Tools

Designed for straightforward personal bookkeeping and multi-currency record management.

Live Currency Conversion

Record transactions in INR, USD, EUR, GBP, JPY, AED, CAD, or AUD. Switch display currencies anytime to convert balances using current exchange rates.

Visual Cash Flow Analytics

Chart.js visualizations break down expenses by category and compare total income against expenses.

User Account Isolation

Multi-user architecture with hashed passwords and isolated database records. Each account operates in its own private sandbox.

Data Export

Export your full transaction history to CSV format for spreadsheets or JSON format for structured backup.

Progressive Web App (PWA)

Install FinTrack on your phone or desktop computer as a standalone web application with offline asset caching.

Dark and Light Theme

Switch between dark and light modes with persistent local preferences and synchronized chart palettes.
